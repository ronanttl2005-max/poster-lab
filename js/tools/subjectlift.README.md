# 主体抽离 / Subject · Absence

入口：`#/tools/subjectlift`。上传未加工的原照片，自动产生上方的透明主体与下方的同色剪影；原照片中的阴影、环境与未识别物件仍然保留。不是生成式背景修复，也不是从参考成品恢复原照片。

默认演示为本地 Canvas 分层宇航员插画，蒙版预制，离线即可预览。用户提供的七张图片用于版式参考，不作为 AI 抠图输入，也未改动或移走原件。

## 抠图引擎

- [Transformers.js 3.8.1](https://github.com/huggingface/transformers.js/tree/3.8.1)，Apache-2.0，经 jsDelivr 动态加载。
- 默认 [BiRefNet lite 512 浏览器版](https://huggingface.co/studioludens/birefnet-lite-512)，模型页声明 MIT；使用其 AutoModel / AutoProcessor 预处理、sigmoid 蒙版和原尺寸回采样。fp32 权重约 192 MB（183 MiB）。512 输入避免原版 1024 模型超出 WASM 内存，细线/发丝仍建议检查与修补。
- 可选 [MODNet](https://huggingface.co/Xenova/modnet)，Apache-2.0，适合人像。复杂物件、多人物、气球绳和透明细节建议 BiRefNet 并检查结果。
- 图片最长边限制在 1600 px 后发送到本地 module Worker，WASM 单线程推理，无照片上传、服务器密钥或新增 npm 依赖。模型资源联网下载并由浏览器缓存。服务需通过 HTTP localhost 或 HTTPS 打开；`file://` 下若 Worker 不可用，会提示启动本地服务。
- 下载进度、失败、超时（五分钟）、取消、切换图片、离开页面都有显式处理。切换素材或取消时终止 Worker，旧响应不能覆盖新素材。失败不会伪装成抠图成功。

## 编辑与导出

六组参考配色；彩色网点复用 shared.js 半调算法；画布支持 3:4、2:3、1:1；分屏、主体大小/位置和照片取景独立调整。照片和蒙版始终共享变换，保持轮廓对齐。断开的多个主体保留相对位置一起提取。

原图修补区支持补回、擦除及最近五笔撤销。修补会停止尚未完成的推理。透明 PNG 可直接使用自带轮廓。支持两侧/交界文案、1080/2160 px 宽 PNG 和裁边透明主体导出。2160 px 导出提高版面/文字分辨率，不补造照片细节。

## 校验

`npm test` 包含构图几何、断开主体边界与柔边阈值的回归校验。浏览器需另验实际模型推理、上传、取消、修补、换色、网点与导出。网络不可达时应测试并报告失败状态，而不能仅凭演示判断 AI 链路正常。

2026-09-08：Node 测试通过；Chrome 实测 BiRefNet 对原始人物照片、MODNet 对人物参考图的完整推理。另验证蒙版输出名兼容、画笔前后像素变化与撤销还原、透明 PNG 再导入、取消后的旧结果隔离、失败提示、三种画布比例、2160×2880 导出及 390 px 窄屏无横向溢出。灵感库、风格体系、模板工坊、工具箱路由均已自检。
