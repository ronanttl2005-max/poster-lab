# 几何撞色 / Geometry Pop

入口：`#/tools/geopop`。无需构建或服务器端 AI 密钥。打开即显示内置插画演示；演示的前景层与文案是预先定义的，不是识别结果。

上传照片后，模块 Worker 依次运行自动抠图和图像描述。原照片与透明前景使用同一个缩放矩形，几何元素夹在两层之间。透明 PNG 会保留自带的 alpha，只运行描述模型。更换图片、停止识别、开始手动修补和离开工具都会终止旧 Worker，防止旧结果覆盖新图。模型运行期间修改文案会保留用户输入。

## 运行依赖

- [Transformers.js 3.8.1](https://github.com/huggingface/transformers.js/tree/3.8.1)，从 jsDelivr 按需加载；WASM 单线程运行，避免要求跨源隔离响应头。
- [BRIA RMBG-1.4](https://huggingface.co/briaai/RMBG-1.4)，q8 权重约 44 MB，用于通用前景分离。该模型按 BRIA 的非商业许可提供；商业使用须遵守其商业授权要求。
- [Florence-2-base-ft](https://huggingface.co/onnx-community/Florence-2-base-ft)，q8 英文图像描述，MIT 许可。根据实际描述提取主题生成双行标题，正文保留实际描述再加排版文案；不调用付费接口。描述模型需要下载约 275 MB 的权重，首次使用较慢。

模型文件通过浏览器缓存复用，源照片像素不上传。首次使用需要能够连接 jsDelivr、Hugging Face 及模型文件 CDN；断网或下载失败明确提示，不把背景色阈值分离伪装成语义抠图。连续 180 秒没有模型进度会停止，用户可重试。运行需要支持模块 Worker、Canvas 和 WASM 的现代浏览器，通过 `npm start` 提供 HTTP 页面。

## 交互

- 大、中、小权重按数量归一，最大余数法保证实际总数正确。零权重不分配元素，全部为零时隐藏几何元素。元素宽度分别为画布宽的 39–57%、19–29%、6.5–13%。
- 随机配色保留布局；随机布局保留配色。位置可拖动调整。
- 轮廓视图中白色代表保留，深色代表透明；画笔补回、橡皮擦除，支持撤销上一笔。
- 文字默认在主体背后，可切换到最上层。标题最多三行，过长自动缩小；正文最多七行，溢出显示省略号。标题和文案均可编辑。
- 导出 1500 × 2000 PNG，复用共享导出逻辑和品牌组件；即使正在看轮廓，导出内容也使用海报视图。

## 验证

`npm test` 包含数量分配、布局种子、尺寸层级和描述生成测试。浏览器回归应覆盖：默认演示、实际照片自动抠图/描述、拖动、三个权重为零、透明 PNG、失败重试、连续换图、手动修补和撤销、轮廓视图下 PNG 导出、离开工具取消识别。
